# 🚀 S1mple Workspace

A modern productivity workspace that helps you organize tasks, capture ideas, manage knowledge, and stay focused—all in one place.

### 🌐 Live Demo

**Try it here:** https://newshukla.vercel.app/

---

## ✨ Features

* 📋 Smart task management
* 💡 Visual brainstorming board
* 🧠 Knowledge & note storage
* 📸 Proof of completion tracking
* 📅 Calendar integration & reminders
* ⏱️ Focus mode for deep work
* 🌙 Multiple themes (Dark & Warm Light)
* ⌨️ Keyboard shortcuts
* 💾 Local browser storage

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/S1mple.git
```

Open the project folder and launch:

```bash
index.html
```

No backend or installation is required.

---

## 📦 Data Storage

All data is stored locally using the browser's LocalStorage.

This includes:

* Tasks
* Notes
* Brainstorming content
* Proof uploads
* Workspace preferences

Your data remains on your device and is not sent to external servers.

---

## 🎯 Project Vision

S1mple Workspace is designed to provide a distraction-free environment for planning, thinking, learning, and executing work efficiently.

The goal is to combine productivity, organization, and knowledge management into a single lightweight application.
